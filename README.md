# Budget

La page de l'app Budget (une app de budget à deux). Elle s'installe sur l'écran d'accueil et garde le budget dans l'appareil;
elle parle à son serveur (Google Apps Script) avec une clé propre à chaque appareil.

Ce dépôt ne contient aucune donnée : les noms, les catégories et les montants vivent dans une feuille Google privée.
